# VitaSync - Real-Time Verified Healthcare Management Platform

## Overview
A full-stack healthcare platform connecting patients with verified doctors.

## Tech Stack
Backend:
- Java
- Spring Boot
- Spring Security
- MongoDB
- JWT Authentication

Frontend:
- React
- Vite
- CSS

## Features
- User authentication
- Doctor verification
- Appointment booking
- Doctor dashboard
- Patient dashboard
- Admin management

## Run Locally

Backend:
cd backend/doctorbooking
mvn spring-boot:run

Frontend:
cd frontend
npm install
npm run dev
